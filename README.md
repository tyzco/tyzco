**在做的项目**

**TradeAgent** · Shopify 商家的 AI 售货员（私有仓库，需授权查看）

- 多智能体编排 + 人工在环确认闸；下单前必须买家显式确认，确认/拒绝/改单由正则
  状态机判定，不交给 LLM
- 议价受商家配置的三层参数约束（阶梯折扣 / 自动批准上限 / 让利底线）
- 检索按数据类型分三条路径：结构化目录走关键词、有主键的记录走精确查找、
  非结构化文档才做 RAG
- 评测集绑定目录指纹，目录一变分数自动作废；按查询形态切片报告，
  `descriptive 67.9%` / `中文 0%` 这类短板直接写在 README 里
- 单次请求的每个节点可在面板上逐帧回放（0.1x–1x）
